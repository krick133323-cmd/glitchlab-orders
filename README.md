# glitchLab Orders

Личное Android-приложение для учёта заявок glitchLab.

## Что умеет
- получает заявки с сайта;
- позволяет вручную добавлять заказы, которые пришли не через сайт;
- статусы: Новая / В работе / Выполнена / Отклонена;
- сумма заказа;
- быстрый звонок клиенту;
- количество заказов, выполненных заказов и выручка;
- данные хранятся на сервере в SQLite.

## Установка серверной части
1. Содержимое папки проекта `glitchapp` загрузить в корень сайта.
2. В `orders-config.php` заменить `site_secret` на длинную случайную строку.
3. Убедиться, что PHP имеет PDO SQLite.
4. После установки сайта через существующую `/install/` админку приложение использует тот же логин/пароль.
5. API доступен как `https://ВАШ-ДОМЕН/api.php`.

## Сборка Android
Откройте папку `glitchLab-android` в Android Studio. В приложении при первом запуске укажите адрес API и логин/пароль администратора.

Для релиза обязательно используйте HTTPS.
